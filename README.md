# دادبان | خدمات حقوقی مهدی فرهادی

وب‌سایت فارسی راست‌چین برای معرفی خدمات حقوقی، مشاوره اولیه، تنظیم و بررسی اسناد و پیگیری امور پرونده‌ها در چارچوب مقررات.

## نشانی سایت
پس از فعال‌شدن GitHub Pages، نشانی موردنظر سایت:
https://mehdi13642251f-hue.github.io/dadban-law-/

## امکانات فنی
- طراحی واکنش‌گرا برای موبایل و رایانه
- عنوان و توضیحات متای فارسی و نشانی canonical
- داده‌های ساختاریافته برای خدمات حقوقی و پرسش‌های متداول
- فایل‌های robots.txt و sitemap.xml
- گردش‌کار GitHub Actions برای انتشار خودکار سایت

## وضعیت انتشار
فایل گردش‌کار در مسیر `.github/workflows/pages.yml` قرار دارد. برای انتشار واقعی، GitHub Pages باید در تنظیمات مخزن روی **GitHub Actions** فعال باشد. از طریق اتصال فعلی، امکان تغییر تنظیمات Pages یا تأیید وضعیت نهایی انتشار در دسترس نیست؛ بنابراین تا زمان بررسی نشانی عمومی، انتشار را قطعی تلقی نکنید.

## پیش از معرفی عمومی
- شماره تماس، ایمیل یا لینک پیام‌رسان رسمی را اضافه کنید.
- عنوان حرفه‌ای و شرح خدمات را با مجوز و حدود صلاحیت واقعی تطبیق دهید.
- اطلاعات حساس موکلان را از طریق فرم عمومی یا کانال ناامن دریافت نکنید.
- پس از فعال‌شدن سایت، مالکیت را در Google Search Console تأیید و sitemap.xml را ثبت کنید.
- دامنه اختصاصی را فقط پس از ثبت و تأیید مالکیت به سایت متصل کنید.

## نکته حریم خصوصی
این سایت فعلاً فرم دریافت اطلاعات پرونده ندارد. محتوای آن معرفی عمومی است و جایگزین مشاوره اختصاصی حقوقی یا تضمین نتیجه پرونده نیست.
