# دادبان | خدمات حقوقی

وب‌سایت فارسی و واکنش‌گرای معرفی خدمات حقوقی، آماده انتشار به‌صورت سایت ایستا.

## انتشار خودکار
فایل گردش‌کار `.github/workflows/pages.yml` برای انتشار از طریق GitHub Actions اضافه شده است. برای فعال‌سازی نهایی، در مخزن به **Settings → Pages** بروید و **Source** را روی **GitHub Actions** قرار دهید. سپس زبانه **Actions** را باز کنید و نتیجه اجرای `Deploy Dadban to GitHub Pages` را بررسی کنید. پس از موفقیت، نشانی عمومی در تنظیمات Pages نمایش داده می‌شود.

## پیش از معرفی عمومی
- شماره تماس و ایمیل حرفه‌ای واقعی را اضافه کنید.
- عنوان حرفه‌ای و شرح خدمات را با مجوز و حدود صلاحیت واقعی تطبیق دهید.
- دامنه اختصاصی را فقط پس از ثبت و تأیید مالکیت به Pages متصل کنید.
- برای دیده‌شدن در جست‌وجو، مالکیت سایت را در Google Search Console تأیید و نقشه سایت را ثبت کنید.

صفحه فعلی فرم دریافت اطلاعات پرونده ندارد؛ اطلاعات حساس را در کانال‌های عمومی ارسال نکنید.
